# 口琴復練室

停了一陣子，可以從一個穩定的單音開始。插上 USB 麥克風，工具會逐音顯示簡譜、音名和吹吸提示，聽到你吹對、吹穩才前進。

- [10～15 分鐘口琴復練手冊](docs/practice.md)
- [課程資料](src/lessons.mjs)

## 在自己的電腦開啟

先把 **ReSpeaker XVF3800** 用 USB 接到要練習的電腦。準備 Git、Python 3 和桌面版 Chrome 或 Edge。

```bash
git clone https://github.com/pcpcchen-coder/Harmonica.git
cd Harmonica
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 可把最後一行的 `python3` 換成 `py -3`。也可以下載 GitHub 的 ZIP，解壓縮後在有 `index.html` 的目錄執行最後一行。

1. 瀏覽器開啟 [http://localhost:8000/](http://localhost:8000/)。
2. 選琴型和起始 Do。標準 C 調十孔或 C 調 12 孔半音階可先用 **C4**。
3. 按「啟用麥克風」並允許收音。狀態列要顯示 **ReSpeaker／XVF3800**。若顯示其他裝置，先停止麥克風，再從清單選 XVF3800 並啟用。
4. 先按「聽目標音」，等參考音播完，再照目標吹。達到當課的持音時間就會往下一音。可以從「找回單音」開始。
5. 練完按「停止麥克風」。在終端機按 `Ctrl+C` 關閉伺服器。

## 支援範圍

| 琴型 | 工具提示 | C 調起點 |
| --- | --- | --- |
| 標準十孔全音階 Richter | 第 4～7 孔吹吸 | 4 孔吹 C4 |
| 標準十二孔半音階 Solo tuning | 第 1～4 孔吹吸，全程放開滑鍵 | 1 孔吹 C4 |
| 複音琴或其他配置 | 音名、八度和簡譜，孔位查原廠音階表 | 依琴型選擇 |

可選 C3～B5 為起始 Do，課程會一起移調。同一調名可能有不同八度，請以音階表或「聽目標音」確認。音高用 A4 = 440 Hz 作基準，預設容許 ±40 cents。第一版判定單音的音高與持音，旋律的拍子請跟手冊另外練；吹吸方向和實際孔位是教學提示。

## 收音與隱私

瀏覽器會優先選名稱含 ReSpeaker 或 XVF3800 的裝置，並要求關閉瀏覽器端的回音消除、降噪、自動增益。「收音設定」顯示實際裝置、音軌設定及收到的聲道，可切換聲道或量測底噪。聲道名稱依網頁收到的順序，從 CH 1 算起。

音訊在本機瀏覽器即時分析。程式不錄音或上傳，只在這個瀏覽器記住完成的課程。麥克風使用作業系統認得的 USB 音訊裝置，工具不修改 XVF3800 韌體或路由。

## 測試

```bash
node --test
```

單元測試用合成波形檢查音高及音程，並檢查持音、中斷與重複音。瀏覽器與實體 XVF3800 的操作驗收見 [復練手冊](docs/practice.md#第一天的收音驗收)。
